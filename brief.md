# Brief — LIGHTS OUT, Part 1

| Item | Decision |
| --- | --- |
| Premise | Late-night scrolling → emergency alert "turn off all the lights around you" → escalating signs → reveal: people changed into uncanny figures drawn to light → inventory → cliffhanger. (user) |
| Single rule | Light attracts the Changed. Everything that helps you survive the dark is itself a light. |
| Takeaway / feeling | Dread that grows beat by beat; viewer becomes aware of their own glowing screen; wants Part 2. |
| Audience | Short-form horror viewers (TikTok/Shorts/Reels), phones, often at night, sound on or off. Captions carry the story with sound off. (default) |
| Format | 1080×1920, 30 fps, ~80 s (tolerance 70–90 s), H.264/AAC. (user: ~80 s) |
| Style | Pixel Dread: pixel sprites, smooth camera/light, word-pop captions, HUD, choice ending. (user) |
| HUD | Series tag `LIGHTS OUT`, part `PART 1`, status `NIGHT 1 · 02:14 AM`; chips appear in the inventory beat. |
| Monsters | Uncanny, no gore: grey skin, glowing white eyes, too-wide smiles, stillness, synchronized turns. (user) |
| Ending | Knock; "Mom" asks you to turn on the porch light; she lives hours away. Choice: TURN IT ON / STAY DARK. (user) |
| Voice | Chatterbox TTS (user). Narrative storyteller voice, mid register, clear, tense, not low/whispery. Audition 2–3 reference voices before full render. Word timing via faster-whisper forced alignment of the exact script. |
| Captions | Burned-in word-pop, yellow = times/objects/numbers, red = danger. |
| Sound | Synthesised drone + alert tones, buzz, knock, one main sting; silence cut before reveals (research R4). Mix ≈ −14 LUFS. |
| Sets needed | bedroom (have), hall (have), street-through-blinds (new), pantry/inventory still life (new), front door interior (have hall + door prop). |
| Audience adaptation | Hook readable in 1 s without sound; one idea per line; no gore; fictional generic alert UI, no real agency/OS branding. |
| Research | research.md (R1–R7). |
| Review mode | User reviews the script, then a voice audition; then I build. |
